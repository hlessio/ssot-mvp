📋 Simple Table Module

Interfaccia tabellare minimale in stile foglio di calcolo

🎯 Demo Interattiva

Come usare la tabella:

  • Inizia digitando il tipo di entità nella prima cella (es: "Contact", "Person", "Project")
  • Clicca sul pulsante + nell'header per aggiungere nuove colonne
  • Clicca sul pulsante + in fondo per aggiungere nuove righe
  • Modifica direttamente nelle celle - i dati vengono salvati automaticamente
  • Click destro su una colonna per rimuoverla
  • Click sul tipo di entità per cambiarlo (attenzione: cancellerà i dati)

💡 Suggerimento

Questa tabella supporta attributi "contestuali" - quando aggiungi una nuova colonna che non esiste nello schema dell'entità, viene creata automaticamente come attributo specifico di questa tabella.

✨ Caratteristiche Principali

🎯 Manipolazione Diretta

Modifica tutto direttamente nella tabella, senza modal o form separati.

⚡ Auto-Discovery

Le colonne vengono create automaticamente analizzando le entità esistenti.

🔄 Sincronizzazione Real-time

Le modifiche si propagano automaticamente a tutti i moduli connessi.

🏷️ Attributi Contestuali

Crea attributi specifici per questa istanza della tabella.

💾 Persistenza Automatica

Tutti i dati e la configurazione vengono salvati automaticamente.

📱 Responsive

Funziona perfettamente su desktop, tablet e dispositivi mobili.
