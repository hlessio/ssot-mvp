# Examples Directory

This directory contains demo and example files organized by complexity and purpose.

## Structure

- **`basic/`** - Simple functionality demos and component tests
  - Basic autocomplete, search, and component demonstrations
  - Unit testing examples
  - WebSocket test interfaces

- **`advanced/`** - Complex integration demos and advanced features
  - Real-time synchronization demos
  - Advanced table functionality
  - Semantic platform demonstrations
  - Multi-module integration examples

- **`phase-demos/`** - Phase-specific development demonstrations
  - Phase 2 testing interfaces
  - SSOT-4000 complete demo
  - Composite document examples

## Usage

To run any demo:
1. Ensure the server is running (`npm start`)
2. Navigate to `http://localhost:3000/examples/[category]/[demo-file].html`

## Key Demos

- **Advanced Real-time Sync**: `advanced/realtime-sync-demo.html`
- **Semantic Platform**: `advanced/semantic-platform-demo.html`
- **Complete SSOT-4000**: `phase-demos/ssot-4000-complete-demo.html`
